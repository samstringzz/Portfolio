# Factory rubric

The judge panel scores a pull request against this file.

## Hard gates (any failure rejects)
- The gate passes: build succeeds and every route returns 200 with a title.
- No personal facts, links or contact details changed unless the issue asks.
- No secrets, tokens or env files added.

## Scored criteria (0 to 5 each)
- Does exactly what the issue asks, no extra scope.
- Small, readable diff that matches the surrounding code.
- Content stays accurate and in UK English, no em or en dashes.
- No accessibility or performance regression (alt text, headings, image sizes).
